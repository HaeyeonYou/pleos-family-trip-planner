이 문서는 "어떤 인상과 규칙으로 만든 디자인인가"를 한 장으로 알려 주는 요약이다. 수치와 근거는 `01-inventory-and-tokens.md`·`tokens.json`, 화면 내용은 `02-screen-summaries.md`, 이미지는 `assets/`에 있다. 사실은 Figma에서 읽은 값이고, "해석"이라고 적은 것만 추정이다.

## 한 줄 컨셉

영유아 동반 가족이 차 안에서 **정차 중에는 차분하게 살피고, 주행 중에는 말 한마디로 끝내는** 케어·코스 앱. 차 자체의 화면(Pleos 공통 UI) 안에 자연스럽게 앉는 "시터노트" 앱 창이다.

## 1. 구조: 차량 셸 + 앱 창

- 화면은 1920x1080이고, 차량 셸(Pleos 공통 UI)이 계기판·상태바·하단 독을 그린다. **우리 앱이 그리는 것은 `App · 시터노트` 프레임 1256x886뿐**이다 (위치 652,76, 모서리 32, 채움 #EEF1F4. 노드 352:2747).
- 앱 프레임 위쪽 가운데에 80x6 그래버(손잡이)가 있다 (352:2748).
- 오버레이(시트·드롭다운·토스트·모달)는 **앱 프레임만 어둡게** 하고 차량 셸은 가리지 않는다. 디자이너가 명시한 원칙이다 (357:1766). 스크림 투명도는 화면에 따라 0.35 / 0.45 / 0.50.
- 셸 변형은 3개다: Light·정차, Dark·정차, Light·주행 (351:2613 / 351:2758 / 351:2903). 다크는 낮잠·수면 화면(C04)에서만, 주행은 D01에서만 쓰였다. Dark·주행 조합은 없다.
- 앱 안 화면은 **3열 그리드**: 바깥 여백 24, 열 폭 392, 열 간격 16, 열 x = 24 / 432 / 840. 맨 위에 음성 입력줄(940x64)과 날씨, 그 아래 칩 줄(높이 53), 본문은 y 168~862.
- 기존 왼쪽 메뉴 레일은 없다. **홈·케어·그로우·설정 바로가기는 3열째 맨 아래의 392x92 카드**로 옮겨졌다 (352:3003, H01 노트 357:1716). 코스 상세(H02·H02-1)에는 바로가기와 음성줄이 없고 제목 헤더가 대신한다.

## 2. 색

브랜드 팔레트는 "시터노트 (Naver cue 계열)"로 이름 붙은 인디고·보라 계열이다 (358:5057). 옛 초록(#0E8A5F) 팔레트와 **완전히 다르다**.

| 이름 | hex | 쓰임 (Figma에서 확인된 것) |
|---|---|---|
| Primary | #4D55F0 | 선택 칩 글자·테두리, 선택된 바로가기, 타임라인 점, 정차 모드 적용 중 테두리 |
| Blue | #1F80FF | 그라디언트 시작 |
| Violet | #8A1EE6 | 그라디언트 끝 |
| Soft | #EEEFFE | 선택 칩 채움, 정차 모드 카드, 둘째 코스 선택 상태 |
| Pink / Cyan / Periwinkle | #E9A6F7 / #22C3EE / #7E9BF5 | 팔레트 프레임에만 있고 화면 사용처는 확인하지 못했다 |
| 그라디언트 | #1F80FF → #5B4BF5 → #8A1EE6 | 주 버튼, 음성 버튼, 안내(길찾기) 원 버튼, 프로액티브 카드 (361:5010, 368:5723, 352:2850) |

화면에서 실제로 쓰인 중립색·상태색 (표본은 `01-inventory-and-tokens.md` 4절):

- 앱 배경 #EEF1F4, 카드 흰색, 타일·비활성 칩·보조 버튼 #F2F4F6, 선 #E5E8EB(1~1.5)
- 글자 3단계: 진한 #191F28 / 보조 #4E5968 / 약한 #8B95A1
- 경고(곧): 채움 #FFF3E0, 테두리 2px #E07A00. 경고(지남): 채움 #FDECEC, 테두리 #E5484D (355:5041, 355:5433)
- 다크(C04): 앱 #121418, 카드 #1E2228, 선 #2C313A, 글자 #F2F4F6, 강조 #8C9BFF, 수면 카드 #262B45

해석: 평소에는 중립 회색 위에 **인디고 하나**로 선택·강조를 표시하고, 시간이 급하면(수유 임박·지남) **주황→빨강**으로 신호를 준다. 주요 행동(경유지 추가, 코스 시작, 지금 수유했어요 등)만 그라디언트를 쓴다.

주의: 이전 디자인(HF 01~06, 초록)과 달리 **디자이너 노트의 "초록 버튼" 표현은 옛 표현**이다 (H01 노트 357:1716). 실제 안내 버튼은 그라디언트 원이다.

## 3. 글꼴

- 위계 프레임 이름은 "Pretendard 위계"이지만 파일의 실제 글꼴은 **Asta Sans**다. 디자이너 노트가 "Pretendard가 없어 Asta Sans로 대체"했다고 적었다 (357:1735). 목표 글꼴은 Pretendard로 보이나 앱에 글꼴 번들 여부와 라이선스는 정하지 않았다.
- 자간은 전부 -1.5%, 줄 높이 125% (타입 프레임 기준).
- 10단 스케일 (357:1738~1765): Display 56 Bold(수유 시각 12:30) / Number 44 Bold / Title 1 34 Bold / Title 2 26 Bold / Title 3 22 Bold / Button 20 Bold / Body 1 20 Medium / Body 2 18 Regular / Label 16 Medium / Caption 15 Regular.
- 1 Figma px = 1dp 규칙은 현재 앱과 같다. 단, 앱 창이 1256x886이 아니라 1682x1210dp라는 결정과의 관계는 열려 있다 (`04` 1.2절, `05`).

## 4. 모양 언어

- 모서리: 카드 24, 시트·모달·토스트·앱 프레임 32, 버튼은 알약(999), 칩 24, 태그 10, 아이콘 원은 원형. 자주 쓰인 값 상위는 `tokens.json`의 `radii`.
- 그림자는 거의 쓰지 않고 선(1~1.5px #E5E8EB)과 면 색 차이로 구분한다.
- 아이콘은 **선 아이콘(stroke)**, 둥근 끝, 크기 22~30 (큰 장소 아이콘 40, 날씨 34). 이름 규칙은 `icon/<이름>`이고 목록은 `assets/icons/README.md`.
- 칩: 높이 53, 글자 20 Medium, 선택 시 **#EEEFFE 채움 + #4D55F0 테두리·글자**.
- 버튼 높이는 화면마다 56~96으로 다르다 (카드 안 56, `코스 시작` 72, D01 96). 하나로 통일된 규칙은 없다.

## 5. 인터랙션 원칙 (노트에서 읽은 것)

- 정차 중에만 바꿀 수 있는 것: 모드 편집(C08), 아이 선택(C07). 주행 중에는 음성으로 한다 ("도윤이로 바꿔줘").
- 주행 중에는 목록 대신 **1곳만 음성 제안**하고 "좋아"로 추가, 8초 안에 답이 없으면 닫힌다 (D01).
- 모드 이름과 개수는 고정이다 (음성 호출 때문). 값만 웹앱과 같게 편집한다 (C08).
- 오른쪽 아래 한 칸(392x370)이 **상황 슬롯**이다. 지연 알림, 수유 임박, 수유 지남, 정차 모드 적용 중, 수면, 다음 경유지, 오늘 케어 기록(빈 상태)이 번갈아 들어간다. 겹칠 때의 우선순위는 디자인에 없다 (`03`, `05`).
- 도착 지연 알림은 "지도·주행 정보는 가리지 않는" 프로액티브 카드다 (C01 노트).

## 6. 톤과 문구

- 존댓말 + 부드러운 안내: "~해요", "~할까요?", "바꾸면 뒤 일정이 다시 계산돼요".
- 음성 안내 문구는 따옴표로 보이게 한다 (“애 잔다”, “수유할게”, “방금 수유했어”, “수유실 찾아줘”).
- 숫자 표기: 시각 12:30, 거리·시간 `1.2km · 3분`, 개월 `14개월`.
- 샘플 문구(`OO몰 2F 수유실`, `△△ 휴게소`, `최근 3회 방문`)는 실제 데이터가 들어갈 자리다. 같은 장소의 거리가 화면마다 다르게 적힌 곳이 있어(구리시 육아종합지원센터 1.2km·3분 vs 2.1km·7분) 샘플로 봐야 한다.
