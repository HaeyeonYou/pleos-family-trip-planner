## 8. 확인 못 한 것 · 이상한 점

1. 글꼴: 위계 프레임 이름과 노트는 Pretendard, 실제 파일 글꼴은 Asta Sans. 코드 쪽 Pretendard 지정을 Figma 값으로 그대로 옮기면 안 된다 (357:1735).
2. 셸 변형 수: 공통 UI 세트는 3개 변형 (Light/Off, Dark/Off, Light/On). Dark+On 변형은 없다 (351:3048).
3. 셸 Drive=On의 색 전체 1:1 비교는 자식 순서가 달라 미완료. 확인된 차이만 기록.
4. C04 (다크 화면) 안쪽 앱 콘텐츠 색은 전체 집계에 섞여 있어 화면별로 분리하지 않았다.
5. K3~K14 기능 코드의 정의표는 Figma 안에서 찾지 못했다. 노트 본문에 K 번호가 있을 뿐이다. 개발 계획서에 K6 언급은 있다.
6. 대표 용도 중 "추정"으로 적은 것 (주황 = C05 임박, 빨강 = C06 지남, 회색 면 #C9D2DC 등)은 노트 문구와 맞춘 추론이다. 노드 단위로 확정하지 않았다.
7. 일부 hex (#3182F6, #C9D2DC, #4F7BFF, #8E96FF, #9B6BFF, #FDE68A, #FFF3E0 등)는 용도를 Figma 안에서 확인하지 못했다.
8. 로고 워드마크 (358:5056) 글자 크기와 굵기는 상세 조회하지 않았다.
9. 근거 노드 id는 조회 시점(2026-11-10) 기준이다. Figma 파일이 바뀌면 id는 유지되어도 값이 달라질 수 있다.
10. 화면 간 셸 인스턴스 id가 화면마다 다르다 (예: 352:2602, 353:2746). 같은 변형이라도 인스턴스 id는 화면 수만큼 있다.
