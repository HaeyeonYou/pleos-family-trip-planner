## 파일 이름 규칙
- `jelly-<캐릭터>-<단계>.svg`: 단계 `drop` = `Stage=Lv1 방울`(경험 1–3개), `puff` = `Lv2 몽글`(4–9개), `born` = `Lv3 캐릭터`(10개 이상). 앱 `JellyStage.DROP/PUFF/BORN`과 같다.
- `png/jelly-<캐릭터>-<단계>@2x.png`: 같은 그림의 PNG 2배. **크기가 400x400이 아니다**(예: 수달 탄생 427x462). Figma가 흐림 그림자가 프레임 밖으로 번진 부분까지 넣어 내보냈기 때문이다. 화면에 놓을 때는 가운데 정렬하거나 SVG의 `viewBox`를 기준으로 맞춘다.

## 앱에 옮길 때 알아 둘 것
- 36개 SVG 모두 `filter`(`feGaussianBlur` 그림자 겸 광택)와 `radialGradient`를 쓴다. 안드로이드 `VectorDrawable`은 흐림 필터를 지원하지 않으므로 그대로 변환하면 그림자·광택이 빠진다. 바로 쓰려면 `png/`의 PNG가 낫고, 벡터가 필요하면 그림자를 Compose에서 따로 그리는 식으로 나눠야 한다(추정).
- 그림 안에 글자는 없다(텍스트 노드 없음, 이미지 래스터 삽입 없음).

## 역량 문구: Figma vs 앱
- **Figma에 캐릭터별 역량 문구는 유니콘 하나뿐**이다(탄생 시트 `374:7878`). 나머지 11종은 이 섹션들에 없다(B안 다른 곳에 있는지는 확인하지 못함).
- 유니콘: Figma "보고, 생각하고, 말로 꺼내는 힘과 나와 다른 관점을 받아들이는 마음이 자랄 수 있어요" ↔ 앱 `ART.power` "보고, 생각하고, 말로 꺼내는 힘이 자라요". Figma 원칙("~자랄 수 있어요"로만 말함)과 앱 문구 끝("자라요")이 다르다.
- 유형 이름은 Figma에 `상상의 유니콘형`만 있고(앱과 같음), 한 스푼 이름은 `숲 곰`(앱과 같음).
- 카테고리 이름 차이: Figma 수달 카테고리는 `여행`(성장 규칙)·`여행 · 새로운 곳`(빈 별 추천), 앱은 `여행·탐험`. Figma 칩 짧은 이름 `동물` `책` `음악` `맛` ↔ 앱 `chip` `동물` `책` `공연` `맛집`, 몸놀이는 Figma 칩 `몸놀이 5` ↔ 앱 `놀이`.
