## 4. 확인하지 못한 것

- **실차·실제 STT/TTS**: 음성은 에뮬레이터에서 말할 수 없어 음성 패널의 "문장 버튼"으로만 넣었다. Pleos STT 인식, TTS가 끝난 뒤 다시 듣기, D01 "좋아"를 말로 수락하는 것은 확인 못 함.
- **실제 주행**: Virtual Console로 기어만 D로 바꿨고 속도는 0이다. 주행 중 셸(62km/h)·주행 전환 순간 시트 처리·주행 중 탄생 음성은 실차 필요.
- **C01 도착 지연 알림**: 실제 길 안내 정체 신호가 있어야 떠서 재현 못 함.
- **C03·C05·C06**(수유 정차·임박·지남): 수유 기록 삭제 예정이라 이번엔 재현하지 않았다.
- **C10 수유실 결과 없음**: 판교 근처는 결과가 있어 재현 못 함.
- **O03 "이 차는 안내만 해요"**: 에뮬레이터가 공조를 지원해 볼 수 없음.
- **O04 이름 키보드 입력·음성 입력**: adb로 한글을 넣을 수 없어 확인 못 함.
- **카카오 지도 실제 타일**: 홈·H02 지도는 도식 그림으로 보였다. 실차 네트워크에서 지도 타일이 뜨는지는 확인 못 함(추정: 의도된 도식 지도인지 확인 필요).
- **주행 중 홈·그로우의 버튼 동작**: 화면만 캡처했고 누르지는 않았다.
- **웹 화면의 폰 실기기 표시**: 375 폭 브라우저로만 봤다. 비교 이미지는 만들지 않았다(웹 Figma는 S02·S02-1 글만 비교).
- **다른 세션과 에뮬레이터 공유**: 감사 도중 child-mode 세션이 에뮬레이터를 쓰는 동안 감사 앱이 설정·O02·O03 화면으로 바뀌어 있었다. 다른 세션의 조작인지, 앱이 스스로 바뀐 것인지 가리지 못했다. 다시 시작하면 정상(로그인 유지, 설정 탭)으로 열렸다.
- **G01 아이 바꾸기**: 그로우가 아이별로 갈리는지(도윤 선택 시) 확인 못 함.
- **코스 저장 중복**: 같은 코스를 두 번 저장하면 둘로 쌓이는지 확인 못 함.
