## 목표
흩어진 세션별 앱을 지우고 깨끗한 상태에서 main 하나로 처음부터 끝까지 확인한다. 통과하면 NAS에 서버 환경을 만든다.

## 순서와 완료 조건
1. **정리:** 에뮬레이터(user 10과 user 0)에서 세션별 접미사 앱(`.care`, `.home` 등 `pm list packages`로 확인)을 모두 지운다. 남기는 앱은 없다(새로 설치). 남은 내비 안내(K현대미술관 등)가 있으면 취소한다.
2. **서버:** main 최신으로 로컬 서버 다시 시작, `alembic upgrade head`, 서버 테스트 전체 통과.
3. **앱:** main 최신으로 단위 테스트 전체 통과, 기본 applicationId(접미사 없음)로 빌드해 user 10에 새로 설치.
4. **처음부터 흐름(캡처 남김):** O01~O06 온보딩(QR 로그인, 아이 정보 — 12개월 이하 아이와 초과 아이 각 1명) → H01 홈(날씨·연료 타일·추천 코스) → H02 코스 상세·대체 장소 → 코스 시작 → 내비 주행 시뮬레이션으로 H03 경유지 도착 → H03-1 → H04 종료 → 방문 기록 → G01 그로우·G03 캘린더 → 케어(12개월 이하: 수유 타이머, 초과: C05-T1) → C08 모드·적용 시점 → D01 주행 중 음성 → 폰 웹 로그인·확인.
5. 문제는 이슈로 남기고, 접수 전 필수인 것만 고친다.
6. 결과 표를 이 파일 진행 로그와 `docs/HANDOFF.md`에 적는다.
