## 목표
홈 3열의 `정차 공간 찾기` 타일을 Figma H01(피드백 `369:12016`)의 **주행 가능 거리 타일**로 바꾼다. 코스를 다 돌기에 연료(배터리)가 모자라면 주유소·충전소를 경유지로 넣는다(디자이너 메모). 반경 칩은 Figma "반경 설정" 5~50km 슬라이더로 바꾼다.

## 완료 조건
1. **연료 타일:**
   - 노란 게이지 원 안에 "N km"(`VehicleState.rangeRemainingMeters`), 태그 "충분"(초록)·"부족"(분홍), 아래 "주행 가능 거리", [주유소 찾기](EV면 [충전소 찾기]).
   - 값이 없으면(시뮬레이터·SDK 실패) "주행 가능 거리 확인 중"으로 보이고, 가짜 숫자는 쓰지 않는다.
   - "부족" 기준은 QP2에 따른다.
2. **[주유소 찾기]:** 경로 위나 근처의 주유소·충전소 1곳을 고른다. 시안의 "△△ 휴게소 · 1.2km · 3분 · 경로 위" 줄이다. 누르면 그곳을 내비 목적지 또는 경유지로 넣는다. 검색 출처는 QP3에 따른다.
3. **코스 경유지 자동 넣기(QP1이 "넣는다"일 때):** 코스 총 거리가 주행 가능 거리 × 여유율보다 길면, 서버(또는 앱)가 중간에 주유소·충전소를 경유지로 넣는다. H02 타임라인에 "주유 · N분" 줄을 넣는다. 판정은 순수 함수와 단위 테스트로 만든다.
4. **반경 설정:**
   - 칩 "반경 Nkm ⌄"를 누르면 제목 "반경 설정", 5km~50km 슬라이더, 아래 "반경 Nkm · 결과 N개"가 나온다.
   - 서버 반경 상한이 50km를 받는지 확인하고, 안 되면 서버도 고친다.
   - 감사 H-17이 "구현됨"이라 한 것과 코드(5·10·20 목록)가 다른 이유를 먼저 확인한다.
5. 정차 공간 찾기(급한 케어 C11)는 케어 화면에 그대로 남긴다. 홈 타일만 바뀐다.
6. 검증:
   - 단위 테스트: 부족 판정, 경유지 넣기, 슬라이더 값 → 요청 반경.
   - 에뮬레이터 캡처: 충분, 부족, 값 없음, 반경 슬라이더. 주행 가능 거리는 Virtual Console로 바꿀 수 있는지 확인한다.
   - 이 파일의 진행 로그와 `docs/HANDOFF.md` 자기 행을 갱신한다.
