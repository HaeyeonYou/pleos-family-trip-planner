## 목표
그로우 탭을 Figma G01 최신안 "경험 젤리"로 바꾸고, "월별 보기"에서 G03 월별 캘린더를 연다. 시연용이 아니라 실제 방문 기록으로 동작하게 만든다.

## 완료 조건
1. **[필수] G01 가운데 카드(G-1, F-1):** 제목 "서아의 경험 젤리"(고른 아이 이름), 설명 "N개의 경험 · M개의 젤리가 자라는 중 · 한 분야 10개면 캐릭터가 태어나요". 가장 많이 간 분야를 가운데 크게, 나머지를 점선 타원 궤도 두 개 위에 놓는다. 아이 원·분야 선은 없앤다. 단계별 크기: 방울(1–3)·몽글(4–9)·캐릭터(10+). 빈 분야는 점선 원 "과학 ?" 꼴(QF2 제안: 최대 4개). 최근 탄생은 말풍선 "11.07 유니콘 탄생". 아래 안내 "젤리를 누르면 그 분야 카드와 다녀온 코스를 볼 수 있어요".
2. **[필수] 오른쪽 아래 "경험젤리 만들러 갈까요?"(G-4, F-1):** 많이 감·적게 감·안가봄 3줄. 각 줄은 배지 + 장소 이름 + 젤리 진행("곰 7/10 · 3번 더 가면 곰이 태어나요") + 바로 안내 버튼. 고르는 규칙은 QF1(제안 ③: 많이 감·적게 감은 다녀온 장소, 안가봄은 그 분야 근처 장소 검색 1회). "다시 가볼까요?" 블록은 없앤다.
3. [좋음] 칩 줄(G-2, F-2): "전체 / 분야 N … / 이번 달", 분야 칩은 개수 순, 칩에 아이 칩은 넣지 않는다(아이는 음성 줄 아바타로).
4. [좋음] 오른쪽 위 카드(G-3, F-3): "이번 달 N곳 · 지난달보다 +K곳" + "월별 보기 ›" + "이번 달 만난 젤리" 그림. "분야별 보기" 카드는 없앤다.
5. [좋음] G03 월별 캘린더(X-1, F-4): 월 칩(이번 달·지난 3달·올해 전체), ‹ › 달 넘기기, 날짜 칸에 그날 자란 젤리 방울(분야 색), 탄생한 날 캐릭터 그림 + "탄생" 배지, 오늘 표시, 오른쪽 "N월 요약 N곳 · N일 / 젤리 N개 자람 · 새로 태어난 젤리 N" + "이번 달 자란 젤리" 분야별 진행 막대. 날짜 탭 → 그날 방문 장소 목록(QF3 제안, 사진 없음). 뒤로(‹) → G01.
6. [좋음] 젤리 탭(G-6): 그 분야 카드(캐릭터·단계·역량 문구) + 다녀온 장소 목록.
7. [나중] 음성 줄 예시(G-5): G01 "유니콘 젤리 보여줘", G03 "지난달 젤리 보여줘". 음성 "지난달 젤리 보여줘"는 G03 지난달로 연다(`grow/GrowVoice.kt`).
8. 테스트: 배치·단계 판정·추천 3줄 고르기·달력 날짜 묶기 단위 테스트, 에뮬레이터 캡처(G01·G03, 방문 0건·1건·많음).
9. 문서: 이 파일 진행 로그, `docs/HANDOFF.md` 자기 행, 감사 문서 6-2 표 해당 줄에 "반영 PR #N" 메모.
