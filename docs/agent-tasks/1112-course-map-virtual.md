## 6. 확인하지 못한 것
- 다크(수면) 톤에서 지도 색은 캡처하지 않았다(토큰만 `SitterSurface`를 따름).
- path가 빈 코스(출발 고리 없이 1번 핀에서 시작)는 단위 테스트로만 확인했고 화면 캡처는 없다.
- Figma와 다르게 남은 점: 홈 H01은 Figma에서 출발 지점이 탑승 카드 밑에 가려져 선만 들어오지만, 앱은 출발 고리가 카드 위에 보이게 여백을 둔다. 라벨 내용은 "이름 · 수유실"까지이며 Figma의 층 정보("2F")는 데이터가 없어 넣지 않았다. 핀이 실제 위치를 대략 따르므로 Figma처럼 늘 대각선으로 고르게 놓이지는 않고, 되돌아오는 구간은 휜 곡선으로 보인다. 공원·물길·격자 위치는 고정 장식이라 실제 지형과 무관하다.
- 위치를 순위와 섞어 펼치므로 핀 사이 거리는 실제 거리 비율과 다르다(사용자 결정대로 '대략').
- 장소가 아주 가까우면 핀을 벌려도 이름표 일부가 생략된다(예: 3번). 의도한 동작이다.
- `docs/HANDOFF.md` 3절 기술 스택 표의 "카카오맵 SDK 2.15.2"는 공용 행이라 고치지 않았다. 메인 세션이 지워 주면 된다.
- 루트 `.env`의 `KAKAO_NATIVE_APP_KEY` 값은 이제 앱이 읽지 않는다(서버의 `KAKAO_REST_API_KEY`는 그대로 씀).
