## 5. 기존 코드와의 관계
- 지금 첫 실행: 계정이 없고 이번 실행에서 건너뛰지 않았으면 `Routes.LOGIN`(QR)부터(`MainActivity.kt:172`). 건너뛰기는 메모리 값(`AccountStore.skipped`)이라 다음 실행에 또 뜬다 → 온보딩 완료 플래그로 바꾼다.
- 폰 웹 가입·로그인: 서버 `/signup`·`/login`·`/car`(`server/app/auth/web.py`), 가입 후 단계 `/start`·`/start/child`·`/start/care`·`/start/car`(`web_start.py`) — 웹 S02·S02-1과 같은 데이터. 차 O04에서 입력한 값과 같은 `Child`로 저장해야 "웹앱에서 입력해도 같은 데이터"(O04 Note)가 된다.
- 차 QR 로그인: `POST /auth/car-login` → `GET .../qr.png` → `POST .../poll`(`server/app/auth/api.py:55~87`, `expires_at` 있음). 로그인 뒤 `ServerSync`가 가족·수유·방문·프리셋을 맞춘다(차 기록도 계정으로 올라감 = O02 "합쳐져요").
- 아이 정보: 차 `Child(birthYear, birthMonth, name, serverId)`, 서버 `ChildIn`(`nickname`, `birth_month` YYYY-MM, `feed_interval_minutes`, `nap_count`, `nap_times`, `stroller_use` …). 코스 요청에는 개월 수만 보냄(#47).

## 6. 서버에 필요한 것 (2026-11-11 결정 반영)
- (QO2) 생년월일을 **일까지** 저장: 아이 정보에 `birth_date`(YYYY-MM-DD) 추가, 기존 `birth_month`는 하위 호환으로 유지(birth_date에서 계산). 웹 S02도 일까지 받도록 맞춘다. 코스 요청에는 지금처럼 개월 수만 보낸다(#47). 출산 예정일 모드는 범위 밖(미래 날짜 선택 불가).
- (QO4) 카시트 뒤보기 `rear_facing_seat`(아이별 bool)를 서버에 저장하고 웹과 동기화.
- (QO9) 자주 가는 케어 장소 목록 API: 차의 도착 기록으로 만든 케어 장소를 서버에 올리고, QR 연결 때 내려받는다.
- (QO5) 보류 — 사용자가 답을 받는 대로 알려 주기로 함. 그때까지 프리셋은 계정 단위 그대로.
- 온보딩 완료 여부는 서버 불필요(추정).

## 7. 결정 (2026-11-11 사용자, 상세 질문은 `05` H절)
- **QO1 경로:** `O01 → (QR이면 O02) → O03 권한 → O04 → O05 → O06`. 단계 번호는 경로마다 다시 센다. QR로 아이를 불러와도 O03은 거치고, 그때는 O04를 건너뛴다.
- **QO2 생년월일:** 일까지 저장(위 6절). 예정일 모드 없음.
- **QO3 수유 간격:** **수유 기록 기능 자체가 삭제될 예정**이라 온보딩에서는 수유 간격·수유 방식 입력을 미리 뺀다. 기존 수유 코드는 이 작업에서 지우지 않는다(삭제는 별도 작업).
- **QO4 함께 챙길 것:** 유모차 → 아이 값, 반려견 → 가족 값, 카시트 뒤보기 → 서버 `rear_facing_seat`.
- **QO5 아이별 모드 값:** **보류**. O05 카드의 모드 줄은 가족 공통 값을 보여 주는 것으로 임시 구현하고, 결정이 오면 바꾼다.
- **QO6 권한:** 캘린더 행은 비활성 "준비 중"으로 보여 준다. 음성 끔 = 마이크만 숨김, 필수 권한 거절해도 진행하고 해당 기능만 "안내만".
- **QO7 나중에 하기:** → 홈(H01). 아이 정보가 없으면 홈에 "아이 정보를 넣으면 맞춰 드려요" 카드 1장. 설정 > 아이 정보에서 O04부터 다시.
- **QO8 주행 중:** 앱 공통 규칙을 따른다. 버튼·칩은 허용, 키보드 입력(아이 이름 등)만 막는다. O01 Note의 "정차하면 이어서" 전체 덮기는 하지 않는다.
- **QO9 케어 장소 불러오기:** 서버 목록 API를 만든다(6절).

## 9. 확인하지 못한 것
- (#184) 한글 이름 입력은 adb로 넣을 수 없어 키보드로 친 화면은 QR로 불러온 '서아'를 편집하는 화면으로 대신 확인했다. 이름 음성 입력(마이크)은 에뮬레이터에서 말하지 못해 확인하지 못했다.
- (#184) 공조 미지원 차의 "안내만" 상태는 에뮬레이터가 공조를 지원해 화면으로 보지 못했다(로직 테스트만).
- (#184) 첫 실행에서 `나중에 하기`로 O03을 건너뛰면 권한을 묻지 않아 알림 꺼짐 띠가 뜬다(다음 실행부터는 기존처럼 시작할 때 묻는다).

- Pleos SDK에서 "문·정차 상태", "차량 정보" 권한이 앱 권한으로 따로 있는지 확인하지 못했다.
