## 4. 확인하지 못한 것
- **NAS에서 로그인한 뒤의 검사 전부**(폰 웹 화면, 차 QR 로그인, 차-웹 동기화, PR #260 `/m/course`). 에이전트는 시험 환경 표시가 없는 외부 주소에 계정을 만들거나 비밀번호를 넣지 않는다. 로컬 서버에서 같은 코드로 대신 확인했다. 사용자가 NAS 시험 계정으로 브라우저에 로그인해 주면 이어서 할 수 있다.
- NAS 앱이 "최종시험 (final1111) 로그인 중"으로 남아 있고 동기화 성공 로그가 찍혔다. NAS DB에 그 계정·세션이 왜 유효한지는 확인하지 못했다.
- 차에서 끝낸 방문(10분 이상)이 웹 그로우에 뜨는지(시뮬레이션은 6분·2분 머묾), C01 도착 지연 알림, C10 결과 없음, H01-3 연료 부족, 귀가 구간 주행 도착.
- 실제 마이크 입력, 실제 공조 적용, 밝은 화면의 D01 카드, 홈 외 화면의 좁은 창 배치, 웹 기록·계정 삭제 실행.

## 5. 검사 방법 메모 (다음 사람용)
- Virtual Console 기어: `adb forward tcp:8088 tcp:8088` 뒤 `POST /browser/session?client=<이름>`을 2초마다 보내 세션을 살려 두고 `PUT /vehicle/gear?gear=Drive|Park`. 세션이 없으면 `{"error":"emulator_inactive"}`.
- 내비 도착: 코스 시작 → 내비 설정(톱니) 2초 길게 → 주행 시뮬레이션 시작 → 진행 막대를 끝으로 끈다. 구간당 3~10분.
- 차 QR 코드는 스크린샷을 macOS CoreImage(QR 검출)로 읽어 웹 `/m/car?code=`로 승인했다.
- 남은 것: 로컬 DB 시험 계정 `fullchk1112`(비밀번호는 레포에 없음), NAS 앱의 검사 흔적(저장 코스 1개, 수유 기록, 방문 2건, 수면 모드 켜짐).
