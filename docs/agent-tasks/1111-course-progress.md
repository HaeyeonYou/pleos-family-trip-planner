## 목표
코스 안내 중 장소에 도착해 앱으로 돌아왔을 때 보이는 화면(지금 `GuideScreen`)을 Figma H03·H03-1·H04대로 새 셸에 맞춰 바꾼다. 다음 행동(다음 장소·장소 바꾸기·귀가·한 곳 더·여기서 끝내기)을 버튼과 음성으로 고를 수 있게 한다. 시연용이 아니라 실제 안내·방문 기록·웹 동기화로 동작해야 한다.

## 완료 조건
1. **H03 경유지 도착:** 위 띠 "코스 진행 중 · N/M 장소", 제목 "N번째 장소 도착", 보조 "내비 안내가 끝나 시터노트로 돌아왔어요". 카드 "OO에 도착했어요"와 "N분 머문 뒤 HH:MM에 출발하면 다음 일정 그대로예요"(뒤 일정과 맞지 않으면 그만큼 늦어진다고 알림). 진행 줄(출발·장소·귀가 + 시각, 지금 위치 강조)과 "남은 일정" 목록. 버튼 3개:
   - [다음 장소로] "다음 장소 · N분 거리"
   - [장소 바꾸기] "다음 장소 대신 다른 곳" → H02-1 대체 고르기를 그대로 쓰고, 고르면 그곳으로 안내
   - [귀가] "우리 집 · N분 · 코스 끝" → 집 안내를 시작하고 H04로 간다
2. **H03-1 마지막 장소:** 다음 장소가 없으면 [귀가]가 기본 버튼이다. [한 곳 더 가기] "근처 추천 장소 고르기"는 H02-1 형식으로 근처 후보를 받아 코스 끝(귀가 앞)에 붙인다.
3. **H04 코스 종료:**
   - 종료 시점은 Figma 정책을 따른다. [귀가]나 [여기서 코스 끝내기]를 고른 순간 끝난다. 지금처럼 집에 도착할 때 끝나지 않는다.
   - 화면 구성: "오늘 코스를 마쳤어요 · 코스 이름 · 시작–끝 · N곳", 다녀온 장소 목록, 경험 젤리 요약과 [경험 젤리 보기](→ 그로우), [홈으로].
   - 귀가를 골랐으면 왼쪽에 "우리 집으로 안내 중 · N분 · HH:MM 도착 예정 · Pleos 내비로 안내를 넘겼어요"를 보인다.
4. **[여기서 코스 끝내기]:** H03·H03-1 어딘가에 둔다(Figma 버튼 위치가 없으므로 작은 텍스트 버튼). 누르면 안내를 취소하고 H04로 간다. 지금 [안내 끝내기]를 대신한다.
5. **기록:** 다녀온(도착한) 장소만 방문·경험 젤리로 기록하고, 건너뛰거나 바꾼 장소는 기록하지 않는다(지금 `GuideSession.recordArrival`이 이미 도착 때만 기록하는지 확인). 바꾼 일정은 서버 코스에 반영해 웹앱에서도 보이게 한다(Figma "바꾼 일정은 웹앱에도 바로 반영돼요"). 서버 API가 없으면 서버 변경을 같은 PR에 넣는다.
6. **음성:** H03 "다음 장소 가자"·"바꿔줘"·"집에 가자", H03-1 "집에 가자"·"한 곳 더". 주행 중이면 같은 질문을 음성으로만 묻고, 답이 없으면 화면을 그대로 둔다(버튼은 주행 중에도 허용, 키보드만 막는다는 사용자 결정 유지).
7. 문구는 "경험 나무" 대신 "경험 젤리"로 쓴다(F-6). 수유 관련 줄은 넣지 않는다(수유 기록 삭제 결정).
8. 검증:
   - 단위 테스트: 단계 판정(가운데/마지막/종료), 출발 시각·지연 계산, 한 곳 더 붙이기, 기록 대상.
   - 에뮬레이터 캡처: 도착 → H03 → 장소 바꾸기 → 마지막 H03-1 → 귀가 → H04. 기어 D일 때 음성만 묻는 상태도 찍는다.
   - Figma와 비교한 이미지를 `docs/screenshots/`에 둔다.
