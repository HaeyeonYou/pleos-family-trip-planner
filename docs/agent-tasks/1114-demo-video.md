## 2. 장면 구성 (제안, 바꿔도 됨)
1. 제목 카드: 차곡 · 팀 유니콘 · "아이와의 하루 외출을 차에서 차곡차곡"
2. 온보딩 O01 → 권한 → 아이 정보(이름·생년월일) → 준비 완료
3. Ready: 홈 추천 코스 3개, 반경 슬라이더, 코스 상세(장소마다 60분, 주차 펼침, 대체 장소)

5. Care: 수유 타이머, 음성 문장 "애 잔다" → 수면 모드(화면 어둡게), 수유 임박 → 경로 위 수유실 → 경유지 추가
6. 주행 중(기어 D): 키보드 잠금, 1곳 음성 제안 [좋아·추가]
7. 코스 종료 H04 → Grow: 경험 젤리(10분 이상 머문 곳이 젤리가 됨)
8. 마무리 카드: 저장소 주소, 폰 웹 주소

## 4. 확인하지 못한 것 / 발견한 문제
(코드는 고치지 않음. 사실과 추정을 나눠 적음)

발견한 문제(관찰한 사실):
1. **음성 패널이 에뮬레이터 마이크 소리를 먼저 받아씀:** 패널을 열면 "고령화도 먼저", "이게 원래 한계에 일공인으로…" 같은 엉뚱한 문장이 '듣고 있어요'에 뜸(호스트 마이크 소리로 추정). 첫 "애 잔다" 버튼에서는 "시간 안에 말씀을 듣지 못했어요"가 나왔고, 다시 누르니 정상 동작. 실차에서 문장 버튼과 실제 인식이 겹칠 때의 처리 확인 필요.
2. **주행 중 "애 배고프다" 버튼:** 누른 뒤 패널이 닫히고 화면에 보이는 응답이 없었음(수유 관련 제안이나 안내 문구 없음). 의도한 동작인지 확인하지 못함.
3. **[다음 장소로] 첫 번째 누름:** 내비가 경로 없이 빈 지도("어디로 갈까요?")로 열림. 앱으로 돌아와 한 번 더 누르니 정상 안내. 재현 여부는 확인하지 못함.
4. **H04 시간 표시:** 실제로는 12:40 출발, 13:10에 끝냈는데 H04가 "12:40 – 14:28"(계획 시각표 기준)로 표시. 머문 시간은 실제 값(12분).
5. 두 번째 장소(2분 거리)로 출발하자 "0분 뒤 도착해요" 헤드업이 뜸(문구 어색).
6. 홈 주행 가능 거리 타일이 0km '부족'으로 나옴(에뮬레이터 연료 값이 0이라 그런 것으로 추정).

촬영 방법 메모:
- 내비 주행 시뮬레이션의 진행 막대는 `adb input swipe`·`motionevent`로 끌리지 않음 → 실제 시간으로 기다림(약 15분).
- 자막(drawtext)에는 Homebrew `ffmpeg`가 아니라 `ffmpeg-full`이 필요(`/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`). 자막 폰트는 앱의 `pretendard_bold.otf`(AppleSDGothicNeo.ttc는 기본 인덱스가 한글 글리프를 못 그림).
- 녹화 원본·편집 스크립트는 세션 임시 폴더에만 있음(레포에 안 넣음).

빠진 장면: 폰 웹·QR(로그인 금지 조건), 수유 임박 자동 제안(시간 대기 안 함), 귀가 구간 주행. 상세는 `docs/demo/README.md`.
