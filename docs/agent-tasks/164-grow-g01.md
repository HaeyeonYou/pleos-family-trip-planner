## 4. 결정과 미정
- (확정, Q32) G01 구조 + B안 성장 단계 참고.
- (확정, 2026-11-10 사용자) B안 범위: **12종 젤리 캐릭터 전체를 이번에 도입.** 서버는 다른 세션 몫이라 12분류는 앱이 판정한다.
- (이 작업의 정의, Q33 대체) 분류는 서버 5분야 대신 B안 12분류. `grow/JellyModel.kt` `classify`: 장소 이름 낱말 → 역할(식사·카페 = 맛 탐험) → 서버 분야(nature=자연·숲, exhibition=과학·박물관, experience=만들기, play=몸놀이, pet=동물·교감) → 그 밖은 여행·탐험. 칩은 '전체 + 많이 간 분류 4개 + 이번 달 + 아이(표시만)'. G01의 고정 칩(자연·놀이·체험·맛집)과 다르다.
- (정의) 경험 1개 = 나들이·식사·카페 방문 중 10분 이상 머문 것(떠난 시각이 없으면 지금까지). 성장 단계는 누적(방울 1~3·몽글 4~9·탄생 10+), 조합 유형은 최근 6개월 1·2위. "37개의 경험 · 9개 장소" = 경험 수 · 서로 다른 장소 수. "이번 달 N곳" = 이번 달 경험한 서로 다른 장소, 지난달 대비. "새로 해본 분야" = 처음 경험한 달이 이번 달인 분류.
- (정의) 비어 있는 별: 안 가 본 분류 중 자연→과학→책→만들기… 순서의 첫째(모두 가 봤으면 가장 적은 것). 한 분류가 절반 넘으면(경험 4개 이상) 아래 안내 줄이 그 별을 권한다. 점선 별을 누르면 홈(코스 추천)으로 간다.
- (Q34) 장소 노드 탭 = 작은 팝업(분류·횟수·마지막 방문, 좌표가 있으면 '다시 안내', 없으면 그 장소가 든 저장 코스 '코스 보기'). 분류 노드 탭 = 성장 팝업 + 그 분류로 거르기. "다시 가볼까요?" = 마지막 방문 7일 넘은 곳을 많이 간 순 3개, 날짜는 N일/N주 전·M.DD, 수유실 확인된 곳은 '수유실 있음'. 예보 문구는 데이터가 없어 넣지 않음.
- (B안) 탄생: 정차 중 그로우 화면에서 축하 시트(한 번), 주행 중(기어 D·R·N 확인 시)에는 화면 없이 음성 1회. 축하 여부는 기기 `shared_prefs/grow.xml`, 데이터 전체 삭제 때 지운다.

## 6. 확인하지 못한 것
- (#181에서 해결) 젤리 그림은 Figma 원본 PNG로 바꿨다. 역량 문구는 Figma에 유니콘만 있어 나머지 11개는 이 앱이 쓴 문구다(디자이너 확인 필요). PNG의 그림자 여백이 오른쪽·아래에만 있다고 보고 배치했다(36개 모두 확인한 것은 아님, 화면상 어긋남은 보이지 않음).
- 12분류 판정은 이름 낱말 규칙이라 틀릴 수 있다(예: '○○몰'은 서버 분야 play → 몸놀이). 서버가 12분류를 내려 주면 `classify`를 바꾼다(서버 작업 필요).
- 테스트 계정 방문은 웹(서버)에서 넣어 좌표가 없어 "다시 가볼까요?"·팝업의 '다시 안내' 버튼이 나오지 않았다. 좌표 있는 차 도착 기록에서 길안내 요청은 단위 테스트 없이 코드로만 확인.
- 주행 중 탄생 음성은 에뮬레이터에서 기어를 바꿀 수 없어 확인하지 못했다. 정차 중 시트는 확인.
- 음성 줄 예시는 G01의 "지난달 간 곳 보여줘" 대신 실제로 되는 "근처 실내 놀거리 찾아줘"로 바꿨다(그로우 음성 명령은 서버 음성 작업 필요).
- 12분류가 다 차면 장소 라벨이 이웃 젤리와 조금 겹칠 수 있다(분류당 최근 2곳만 보임).
