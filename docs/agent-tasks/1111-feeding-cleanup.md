- 판단 기준은 **지금 선택한 아이**(아이별 케어 모드, child-mode PR #193·#200·#203과 같은 기준). 생년월일은 차 안에만 있으므로 월령 계산은 앱에서 한다(서버는 개월 수만 받음).
