# 작업 기록: 수면 모드(다크)에서 밝게 뜨는 화면 검토

- 상태: **완료(2026-11-13)** · 통제 세션 · 브랜치 `fix/sleep-dark-notify`
- 계기: 사용자 보고 "수면 모드인데 경유지 추천 팝업이 흰색으로 떴음".

## 원인
- 그 팝업은 앱 화면이 아니라 **지연 알림의 시스템 헤즈업 알림**(`navi/DelayAlertController`, 채널 `trip_delay`, 중요도 HIGH, 버튼 `경유지 보기`·`그대로 가기`)이다. 시스템 알림 창은 차 시스템의 주간/야간 설정으로 그려져서(에뮬레이터 `cmd uimode night` = no) 앱이 색을 바꿀 수 없다.
- 도착 알림(`GuideNotifier`)은 수면 모드에서 조용한 채널(LOW)로 가는데, 지연 알림만 수면 모드를 따르지 않아 흰 팝업과 소리가 났다. 수면 카드의 "알림은 소리 없이" 약속과도 어긋났다.

## 고친 것
- 지연 알림: 수면 모드면 새 채널 `trip_delay_quiet`(LOW, 소리·진동 없음)로 보내 헤즈업이 뜨지 않고 알림 목록에만 남는다. 앱으로 돌아오면 케어 화면의 어두운 지연 배너·후보 패널로 본다.
- 앱 안에서 다크일 때 밝게 남던 색(Figma 다크 값이 없어 같은 계열 어두운 값으로 추정):
  - 홈 연료 타일 충분/부족 바탕·게이지 빈칸 (`FuelRangeTile`)
  - 홈 코스 미리보기 지도의 공원·물길 장식 (`CourseMap`)
  - 그로우 만들기 태그 '많이' 바탕 (`ExperienceScreen`)
  - 지연 경유지 후보 패널의 옛 초록 원·흰 글자·주황 옅은 원 (`DelayAlertPanel`) → 셸 토큰(`onPrimary` 등)

## 검토했지만 그대로 둔 것
- 앱 화면 색은 전역 `ToneState` → `SitterSurface.current`·`MaterialTheme`(루트 `Surface`)로 다이얼로그·팝업까지 따라간다(코드 확인).
- primary(다크 #8C9BFF) 위 흰 글자·아이콘(버튼, 태그 등 여러 곳): 대비가 낮지만 Figma 다크에 primary 버튼 글자 값이 없어(`onPrimary` 다크 값도 기어 글자에서 추정) 바꾸지 않았다. 디자이너 확인 필요.
- 그라데이션 원 버튼·C12 그라데이션 카드의 흰색은 배경이 어둡거나 진해 그대로 둔다.

## 확인하지 못한 것
- 에뮬레이터 화면 확인: 전체 검사 서브에이전트가 에뮬레이터를 쓰는 중이라 코드·단위 테스트로만 확인했다.
- 실차에서 야간일 때 시스템 알림이 어둡게 그려지는지.
