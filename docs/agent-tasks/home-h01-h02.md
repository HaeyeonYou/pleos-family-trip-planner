## 1. 목표와 완료 조건
홈과 코스 상세를 11/10 디자인대로 새 셸 위에서 만든다. **1차 제출용(11/14까지)은 H01**: 3열 그리드 홈에서 코스 선택 → 코스 시작까지 한 흐름. 그다음 H02, H02-1.
- H01: 검색/음성 바 + 날씨 + 아이 아바타, 칩 8종(반나절·하루·반경 10km·반려견·수유실 필수·유모차·생후 개월·다시 추천), 1열 지도 카드 + 탑승 감지 프로액티브 카드, 2열 추천 코스 3개(코스 카드 `CourseItem`), 3열 정차 공간·경험 나무 타일 + 최근 방문 코스 3 + 바로가기 독.
- H02: 요약 태그 5종(총 시간, 수유실 수, 유모차, 주차 곳수, 반려동물 — 앱에서 계산), 레일 타임라인(교체·삭제·순서 변경 아이콘 인라인), 도착·수유 여유 카드, `코스 시작`·`경유지 편집`·`코스 저장`.
- H02-1: 3열 인라인 대체 장소 시트(후보 3곳, 거리·경로에서 +N분), `이걸로 바꾸기` → 기존 `/course/schedule`로 재계산.

## 6. 확인하지 못한 것
- 아이 정보 없는 테스트 계정이라 아바타·생후 개월 칩(아이콘 `Users`)은 화면에서 확인 못 함(코드·컴파일만).
- 디자인의 "우리 집/할머니댁/육아센터/등록" 저장 장소 줄은 데이터 출처(앱·서버)가 없어 **만들지 않았다**. 서버에 필요한 것: 가족 저장 장소 목록(`05` Q45 등록 화면 미확인).
- 정차 공간 찾기 타일은 휴게소 데이터(D9)가 없어 문구만 "근처 주차장·쉼터"이고 누르면 케어 탭으로 간다.
- 최근 방문 코스는 저장한 코스(`CourseStore`) 최근 3개이다. 방문 기록(`VisitStore`) 기반이 아니다.
- 코스 이름 규칙은 장소명+분야라 "판교박물관 박물관·전시"처럼 겹치거나, 장소명이 긴 곳("착한토끼키즈카페키즈 룸성남…")은 여전히 말줄임된다. 서버 분야 이름을 더 짧게 할지는 미정.
- "지금 N대"는 데이터 따라 비어 코스 카드가 Figma보다 조금 낮다.
- "반나절"의 5시간 규칙과 칩 필터/값 구분(Q26)은 `05` 추천안을 따른 임시 결정이다. 프로필의 `maxDriveMinutes`는 홈에서 반경 칩 값으로 덮인다.
- ≡ 순서 변경은 드래그 대신 누르면 위/아래 화살표가 나오는 방식(단순화).
- 서버 우회 분·거리(#160)가 화면에 보이는 모습은 확인 못 함: 에뮬레이터가 쓰는 로컬 서버(메인 체크아웃, 8000)가 #165 이전 코드라 어림값으로 보였다. 서버 값 우선·재계산 뒤 지움은 단위 테스트로만 확인. 서버를 main으로 다시 띄운 뒤 확인 필요.
- 경유지 편집 방식은 Figma에 없는 사용자 결정이라, 머무름 줄·`+ 장소 추가` 줄·장소 추가 패널은 Figma 대조 대상이 없다(새 셸 토큰으로만 맞춤).
- 테스트 계정·밤 시간대 코스라 수유실·유모차 태그가 "확인 필요"로만 보였다. 체크 태그 모양은 단위 테스트로만 확인.
