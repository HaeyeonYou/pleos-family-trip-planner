## 1. 목표와 완료 조건
홈과 코스 상세를 11/10 디자인대로 새 셸 위에서 만든다. **1차 제출용(11/14까지)은 H01**: 3열 그리드 홈에서 코스 선택 → 코스 시작까지 한 흐름. 그다음 H02, H02-1.
- H01: 검색/음성 바 + 날씨 + 아이 아바타, 칩 8종(반나절·하루·반경 10km·반려견·수유실 필수·유모차·생후 개월·다시 추천), 1열 지도 카드 + 탑승 감지 프로액티브 카드, 2열 추천 코스 3개(코스 카드 `CourseItem`), 3열 정차 공간·경험 나무 타일 + 최근 방문 코스 3 + 바로가기 독.
- H02: 요약 태그 5종(총 시간, 수유실 수, 유모차, 주차 곳수, 반려동물 — 앱에서 계산), 레일 타임라인(교체·삭제·순서 변경 아이콘 인라인), 도착·수유 여유 카드, `코스 시작`·`경유지 편집`·`코스 저장`.
- H02-1: 3열 인라인 대체 장소 시트(후보 3곳, 거리·경로에서 +N분), `이걸로 바꾸기` → 기존 `/course/schedule`로 재계산.
- 완료 조건: Figma(`docs/design/pleos-1110/assets/screens/H01-home.png`, `H02-course-detail.png`, `H02-1-replace-place.png`)와 구조·값이 같고 실제 코스 데이터로 동작, 테스트와 에뮬레이터 비교 캡처가 PR에 있다. 기존 코스 시작·안내 흐름이 깨지지 않는다.
