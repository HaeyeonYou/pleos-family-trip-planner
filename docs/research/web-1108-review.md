## 3. 디자인과 다르게 하는 것 (이유)

1. **이메일 가입 → 아이디 가입 유지**: 이메일 인증·비밀번호 찾기용 메일 서버가 없고, 이메일은 개인정보를 더 받는 일이라 지금은 아이디(4~20자)를 쓴다. 「비밀번호 찾기」는 없는 기능이라 보이지 않는다. 이메일로 바꾸려면 메일 발송 방법을 먼저 정해야 한다.
2. **약관·개인정보 동의**: 약관 원문이 아직 없어서, 서버가 실제로 저장하는 항목을 그대로 적은 「개인정보 수집·이용 안내」(`/m/privacy`)에 동의를 받는다. 동의 시각은 계정(`users.agreed_at`)에 저장한다. 법무 검토가 필요한 약관 원문은 만들지 않았다. 「알림 수신 동의(선택)」는 알림을 보낼 서버가 없어 뺐다.
3. **S03 데이터 가져오기**: 「계정 없이 차에 쌓인 데이터를 옮길지」는 디자인에도 정책 확인 필요로 남아 있고 차 앱 변경이 필요해 만들지 않았다. 대신 QR로 온 차를 보여 주고 연결한다.
4. **카시트(M01-1)·알레르기·식이 제한**: 쓰는 기능이 아직 없다(카시트→뒷좌석 공조·햇빛, 알레르기→장소 조건 필터). 쓰는 기능이 생길 때 받는다. 알레르기는 건강 정보라 더 신중히 한다.
5. **성향 태그**: S02 필수 항목이라 저장·표시하지만, 추천 코스 입력(`TripConditions`)에 성향 필드가 없어 **아직 추천에 반영하지 않는다**(후속: 경험맵 「동물을 좋아하는 서아라면」 다음 스텝).
6. **홈의 일정 카드·H02·H05·S04·「일정으로」「차에 보내두기」**: 일정 저장과 구글 캘린더는 하지 않기로 결정했다.
