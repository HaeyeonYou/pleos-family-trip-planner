## 3. 디자인과 다르게 하는 것 (이유)

1. **이메일 가입 → 아이디 가입 유지**: 이메일 인증·비밀번호 찾기용 메일 서버가 없고, 이메일은 개인정보를 더 받는 일이라 지금은 아이디(4~20자)를 쓴다. 비밀번호 찾기 링크는 만들지 않는다(없는 기능을 보이지 않음). 이메일로 바꾸려면 메일 발송 방법을 먼저 정해야 한다.
2. **약관·개인정보 동의**: 약관 원문이 아직 없어서, 서버가 실제로 저장하는 항목을 그대로 적은 「개인정보 수집·이용 안내」(`/m/privacy`)를 만들어 동의를 받는다. 동의 시각은 계정에 저장한다. 법무 검토가 필요한 약관 원문은 만들지 않았다.
3. **알림 수신 동의(선택)**: 알림을 보낼 서버가 없어 저장만 하고 알림은 보내지 않는다는 것을 화면에 쓰지 않고, 이 항목은 넣지 않는다(동의만 받고 보내지 않는 일을 피함).
4. **S03 데이터 가져오기**: 「계정 없이 차에 쌓인 데이터를 옮길지」는 디자인에도 정책 확인 필요로 남아 있고 차 앱 변경이 필요해 만들지 않는다.
5. **알레르기·식이 제한**(M01-1 8번째): 건강 정보라 쓰는 기능(장소 조건 필터)이 아직 없어 받지 않는다. 쓰는 기능이 생길 때 추가한다.

## 4. 이번에 반영하는 것

- **온보딩**: QR 랜딩 → 가입 → 아이 정보 1/2 → 케어 정보 2/2 → 차 연결 → 홈. 가입 직후 아이 정보가 없으면 이어서 입력하게 하고, 건너뛰기를 둔다.
- **아이 정보 확장**: 성향 태그, 낮잠 시간대·차에서 잘 자는지, 카시트, 더위·추위, 멀미, 소리, 유모차. 서버 `children` 표에 선택 열로 추가(기존 앱·API 호환, 모두 선택값).
- **쓰는 곳**: 더위·추위 → C03 권장 온도(±1℃) · 소리 → 낮잠 프리셋 권장 음량 · 낮잠 시간대 → 홈 수유·낮잠 안내 · 성향 태그 → 경험맵 「동물을 좋아하는 서아라면」 다음 스텝(후속). 쓰지 않는 값은 받지 않는다.
- **아이콘**: 외부 라이브러리 없이 인라인 SVG(선 아이콘)로 탭바·카드·버튼의 자리표시자를 교체. 색은 기존 토큰(`#263746`, `#68727d`)을 따른다.
